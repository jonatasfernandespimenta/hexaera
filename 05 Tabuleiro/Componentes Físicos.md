# Componentes Físicos (rascunho)

| Componente | Qtd. estimada |
|---|---|
| Tiles de terreno hexagonais | 80–100 |
| Tile Centro (dupla face, por era) | 1 por jogador |
| Miniaturas de construção (estoque limitado por tipo, ex.: 6 casas, 4 fazendas, 3 minas…) 🧪 | ~60 |
| Cartas de referência de construção (custo/produção, uma por tipo) | ~40 |
| Peças de trilho/estrada | 40 |
| Cubos de recurso (cores por tipo) | 150 |
| Moedas | 60 |
| Meeples de população | 30 |
| Meeples de invasor | 15 |
| Cartas de evento (7 eras) | ~140 |
| Cartas de contrato | ~50 |
| Cartas de tecnologia | ~35 |
| Tabuleiro de jogador (trilhas 😊 ☁️ 📚 ⭐ era) | 1 por jogador |
| Tabuleiro de mercado | 1 |
| Livro de campanha + adesivos | 1 |
